# Reem Galal – Portfolio

Static portfolio site (HTML, CSS, Bootstrap 5, vanilla JS) for data analytics and data engineering work.

Pages: `index.html`, `about.html`, `skills.html`, `projects.html`, `contact.html`.

## Before publishing
Search the project for `YOUR_` and replace:
- `YOUR_GITHUB_USERNAME` with your GitHub username (footer of every page, contact page, project buttons)

Hosting: push the folder to a GitHub repo and enable GitHub Pages (or use Netlify / Vercel).

`_unused/` holds the template's Blog and Photography pages (not linked from the site).
