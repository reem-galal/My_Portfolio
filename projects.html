SQL Data Warehouse

Built a SQL Server data warehouse using ETL pipelines, data cleaning, and dimensional modeling to prepare CRM and ERP data for analysis.

SQL Server T-SQL ETL Pipelines Data Modeling

Designed and implemented a SQL Server data warehouse integrating CRM and ERP data. The project follows the Bronze, Silver, and Gold layers to organize raw data, clean and validate records, and prepare analytics-ready tables.

  • Data Sources: Integrated CRM and ERP data from CSV files into SQL Server.
  • Approach: Implemented ETL workflows using T-SQL, applied data cleaning and deduplication, and designed fact and dimension tables using a star schema.
  • Outcome: Created a structured data warehouse that supports customer, product, and sales analysis through clean data and dimensional models.

E-commerce Funnel & Retention Analysis

Analyzed e-commerce user journeys, conversion funnels, customer retention, and RFM segments using SQL and Python.

SQL Python pandas Customer Analytics

Analyzed a synthetic e-commerce dataset using SQL and Python to understand the customer journey, measure conversion rates, study retention, and segment customers based on purchasing behavior.

  • Objective: Understand where users drop off in the purchase funnel and how customer behavior differs across segments.
  • Approach: Used SQL (CTEs, window functions) for funnel and retention analysis, and Python with pandas and matplotlib to analyze customer behavior and visualize results.
  • Outcome: Identified conversion drop-offs, compared customer behavior across devices and channels, and explored customer segments based on purchasing activity.
